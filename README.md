# 🎡 لعبة السبنر (عجلة الحظ) - تطبيق ويب كامل

تطبيق ويب حقيقي (Node.js + قاعدة بيانات SQLite) لعمل لعبة "عجلة حظ" تُستخدم في الفعاليات والمعارض لجمع بيانات العملاء وتقديم جوائز. يتكون من:

- **صفحة اللعبة** (`/play/<رابط-الكامبين>`) - الصفحة اللي بتتفتح على تابلت/شاشة العميل، مفيها: مقدمة (صورة/فيديو + زرار بداية) → فورم بيانات العميل → عجلة الحظ → بوب أب النتيجة (مع احتفال كونفيتي للربح).
- **لوحة تحكم إدارية** (`/admin`) - بتتحكم في كل حاجة: الهوية والألوان، الشعارات (أكتر من شعار بمكان وحركة مستقلة)، شاشة المقدمة، حقول الفورم، أقسام عجلة الحظ (صورة/نص/رمز لكل قسم + نسبة ظهور + ضمان ظهور كل كام لفة)، تصميم بوب أب النتيجة، وبيانات كل العملاء اللي لعبوا مع تصدير إكسل.

كل كامبين (عميل) ليه **رابط لعبة منفصل** تقدر تنشئه وتشاركه، وتقدر تشغّل أكتر من كامبين/جهاز في نفس الوقت من نفس الداشبورد.

---

## 1) التشغيل على جهازك (تجربة محلية)

يحتاج [Node.js](https://nodejs.org) إصدار 18 أو أحدث.

```bash
npm install
npm start
```

هيفتح السيرفر على: `http://localhost:3000`

- لوحة التحكم: `http://localhost:3000/admin`
- أول مرة تشغّل السيرفر، هيتعمل حساب أدمن افتراضي وهيتطبع في الطرفية (Terminal) اسم المستخدم وكلمة المرور:
  ```
  اسم المستخدم: admin
  كلمة المرور:  admin123
  ```
  **غيّر كلمة المرور فورًا** من زرار "كلمة المرور" أعلى الداشبورد بعد أول دخول.

تقدر كمان تحدد بيانات الأدمن الافتراضي من البداية بإنشاء ملف `.env` (انسخ `.env.example`):

```bash
cp .env.example .env
```

وعدّل فيه `ADMIN_USERNAME` و `ADMIN_PASSWORD` و `JWT_SECRET` (مفتاح تشفير الجلسات - غيّره لأي نص عشوائي طويل).

> ⚠️ تغيير `ADMIN_USERNAME`/`ADMIN_PASSWORD` في `.env` بيأثر بس لو لسه معملتش أول تشغيل (يعني قبل ما يتنشئ حساب الأدمن في قاعدة البيانات). لو عايز تغيّر بيانات حساب موجود بالفعل، استخدم زرار "كلمة المرور" في الداشبورد.

---

## 2) إزاي تستخدمها

1. ادخل `/admin` وسجّل دخول.
2. اضغط **"+ كامبين جديد"** واكتب اسم العميل.
3. من صفحة تعديل الكامبين هتلاقي تابات:
   - **الهوية والألوان**: ألوان الخلفية والأزرار والخط.
   - **الشعارات**: ضيف أكتر من شعار، واسحبه جوه معاينة الشاشة عشان تحدد مكانه، وحدد حجمه وحركته (ظهور تدريجي/قفز/تعويم/نبض/دوران) والشاشة اللي يظهر فيها.
   - **شاشة المقدمة**: ارفع صورة أو فيديو، واكتب العنوان ونص الزرار (عربي/إنجليزي).
   - **بيانات العميل**: الاسم ورقم التليفون إجباريين دايمًا. فعّل/ألغِ المنصب والإيميل والاهتمامات وحدد أيهم إجباري، وكوّن قائمة الاهتمامات اللي تظهر للعميل كقايمة اختيار متعددة. تقدر كمان تضيف **حقول تسجيل حرة** (نص أو قائمة اختيار) وتربط أي اهتمام بجائزة قيمة أكيدة (اقرأ التفاصيل تحت).
   - **عجلة الحظ**: حدد عدد الأقسام (زرار "+ إضافة قسم")، ولكل قسم: النص، اللون، نوع النتيجة (ربح / حظ أوفر)، **نسبة الظهور**، **ضمان الظهور كل كام لفة** (مثلاً لو حطيت 10 هيتأكد إن القسم ده يظهر مرة على الأقل كل 10 لفات حتى لو نسبته قليلة)، و**الكمية المتاحة من الجائزة** (اقرأ التفاصيل تحت)، بالإضافة لصورة/رمز داخل القسم وحجم النص ومكانه.
   - **نتيجة اللفة**: صمم بوب أب الربح (مع تفعيل/إلغاء الاحتفال) وبوب أب "حظ أوفر المرة الجاية" (افتراضيًا من غير احتفال، وتقدر تتحكم فيه). الكارت بيعرض تلقائيًا **اسم العميل** و**صورة الجائزة نفسها من العجلة** (لو مرفوعة) فوق صورة البوب أب العامة.
   - **ربط جوجل شيت**: خطوات وكود جاهز لربط اللعبة بـ Google Sheet عشان بيانات كل عميل تتسجل فيه لحظيًا (اقرأ التفاصيل تحت).
   - **بيانات العملاء**: جدول بكل اللي لعبوا (فيه عمود "بيانات إضافية" للحقول الحرة)، وزرار **تصدير إكسل** منظم بكل الحقول، وزرار تصفير عداد اللفات والمخزون (لو عايز تبدأ الكامبين من جديد).
4. من أعلى صفحة التعديل هتلاقي **رابط اللعبة الخاص بالعميل** - انسخه أو خصصه، وابعته للتابلت/الشاشة اللي هتشتغل بيها في الفعالية. تقدر تفتح أكتر من رابط كامبين على أكتر من جهاز في نفس الوقت.
5. زرار **"معاينة اللعبة"** بيفتحلك اللعبة فعليًا في تاب جديد عشان تجربها قبل الفعالية.

### نظام تحديد الجوائز
كل قسم في العجلة له **نسبة ظهور (وزن)** بيتحسب تلقائيًا كنسبة من إجمالي الأوزان. لو حطيت "ضمان الظهور كل N لفة" لأي قسم، السيستم هيجبر ظهوره لو فات عليه N لفة من غير ما يظهر - حتى لو نسبته قليلة. النتيجة بتتحدد في السيرفر (مش في المتصفح) عشان تكون عادلة ومينفعش حد يتلاعب فيها.

### منع تكرار اللعب
النظام بيتأكد من رقم تليفون كل عميل - لو نفس الرقم حاول يلعب تاني في نفس الكامبين، بيظهرله رسالة إنه شارك قبل كده ومينفعش يلعب تاني (تقدر تغيّر نص الرسالة من تبويب "بيانات العميل").

### الكمية المتاحة لكل جائزة (المخزون)
لو عندك عدد محدود من هدية معينة (مثلاً 10 قطع بس)، حط الرقم ده في خانة "الكمية المتاحة" لقسم الجائزة دي في تبويب عجلة الحظ. أول ما العدد ده يخلص، العجلة بتوقف تلقائيًا عن إدية للاعبين الجداد (حتى لو نسبة ظهورها عالية أو عندها ضمان ظهور) وتوزع الباقي على باقي الجوائز - عشان محدش ياخد وعد بجائزة خلصت. تقدر تتابع "المتبقي حاليًا" جنب كل جائزة في نفس التبويب.

### جائزة قيمة لاهتمام معين (VIP)
من تبويب "بيانات العميل"، تحت قائمة الاهتمامات، كل اهتمام فيه خانة "🎁 يجيب جائزة قيمة أكيدة" - اختار منها القسم اللي عايزه. أي عميل يختار الاهتمام ده هياخد الجائزة دي أكيد لما يلف العجلة (مش بالحظ)، طالما لسه متاح منها كمية؛ لو خلصت الكمية، العجلة بترجع تشتغل بنظامها العادي.

### حقول تسجيل حرة
من نفس التبويب، تقدر تضيف أي عدد من الحقول الإضافية في فورم التسجيل - نص حر (زي "اسم الشركة") أو قائمة اختيار بخيارات إنت تحددها (زي "الفرع")، وتحدد كل حقل إجباري أو لأ. الحقول دي بتظهر تلقائيًا في فورم اللعبة، وبتتسجل مع باقي بيانات العميل وبتتصدّر في ملف الإكسل.

### ربط Google Sheet (مزامنة لحظية)
من تبويب "ربط جوجل شيت" في محرر الكامبين هتلاقي خطوات مفصّلة وكود Apps Script جاهز تنسخه. باختصار:
1. اعمل Google Sheet جديد ← Extensions ← Apps Script ← الصق الكود اللي في التبويب.
2. Deploy ← New deployment ← Web app ← Who has access: **Anyone** ← Deploy ووافق على الصلاحيات.
3. انسخ رابط الـ Web App والصقه في خانة "رابط Web App" في نفس التبويب واحفظ.

من ساعتها، كل عميل يلعب ويطلعله نتيجة، بياناته (اسمه، تليفونه، النتيجة، الحقول الإضافية...) بتتسجل في نفس اللحظة في الشيت - مفيد جدًا لفريق استلام الهدايا عشان يتأكدوا من بيانات أي حد جاي ياخد جايزته وهم قاعدين قدام الكاونتر، من غير ما يستنوا تصدير الإكسل.

### الصوت والتفاعل الصوتي
من تبويب "الصوت والتفاعل" في محرر الكامبين تقدر تتحكم في:
- **مفتاح رئيسي** يشغّل/يقفل كل الأصوات دفعة واحدة لكامبين معين.
- **رسالة ترحيب دورية**: بتتقال بصوت (Text-to-Speech) كل ما مدة معينة على شاشة المقدمة، عشان تلفت انتباه أي حد ماشي يقف يلعب. النص والتوقيت قابلين للتعديل بالكامل.
- **نداء العميل بالاسم وقت النتيجة**: نص قابل للتعديل بصوت (Text-to-Speech) بيتقال أول ما تظهر نتيجة اللفة - استخدم `{name}` مكان اسم العميل و`{prize}` مكان اسم الجائزة (نصين منفصلين لحالة الربح وحالة حظ أوفر).
- **صوت لفة العجلة**: صوت "تكة" افتراضي بيتولّد تلقائيًا ويشتغل أثناء اللفة، وتقدر ترفع صوت مخصص بدل منه.
- **صوت الاحتفال بالربح**: صوت احتفالي افتراضي بيشتغل تلقائي وقت الفوز بجائزة، وتقدر ترفع صوت مخصص بدل منه.

ملحوظة مهمة: كل المتصفحات بتمنع تشغيل أي صوت تلقائي قبل أول تفاعل من المستخدم مع الصفحة (قيد أمان عام مش خاص بالتطبيق ده). يعني أول لمسة/كليك على شاشة الجهاز بتفتح الصوت، وبعدها هيشتغل عادي طول الوقت - مناسب جدًا لأجهزة الكشك (kiosk) اللي بتتلمس أول ما حد يقرب منها.

**صوت طبيعي أعلى جودة (اختياري) عن طريق Google Cloud Text-to-Speech**: لو ضفت متغير البيئة `GOOGLE_TTS_API_KEY` (شرح إنشائه في قسم "رفع التطبيق" تحت)، هيستخدم التطبيق تلقائيًا صوت جوجل الطبيعي (WaveNet) بدل صوت المتصفح الآلي لكل من رسالة الترحيب ونداء النتيجة - بدون أي إعداد إضافي في الأدمن. الصوت المولّد بيتخزن مؤقتًا على السيرفر (لنفس النص واللغة) عشان الرسائل المتكررة (زي رسالة الترحيب) متتحسبش عليك تكلفة كل مرة. لو المتغير مش موجود، أو حصل أي عطل مؤقت في الاتصال بجوجل، بيرجع تلقائيًا وبسلاسة لصوت المتصفح المجاني من غير ما تتأثر اللعبة.

## 3) رفع التطبيق على الإنترنت (استضافة)

التطبيق سيرفر Node.js عادي + قاعدة بيانات SQLite (ملف واحد) + مجلد صور مرفوعة. يشتغل على أي استضافة بتدعم Node.js مع تخزين دائم (Persistent disk/volume) للمجلدين `data/` و `public/uploads/`.

### الطريقة الأسهل: Docker

لو عندك سيرفر خاص (VPS) أو استضافة بتدعم Docker:

```bash
docker compose up -d --build
```

هيشتغل على المنفذ 3000. عدّل `docker-compose.yml` وحط بيانات الأدمن والمفتاح السري بتاعتك قبل ما تشغّله.

### استضافات جاهزة (Railway / Render / أي PaaS يدعم Node)

1. ارفع المشروع على GitHub (مجلد `node_modules` مستبعد أصلاً في `.gitignore`).
2. اربط المستودع بالمنصة (Railway.app أو Render.com من أشهرها وسهلين).
3. Build command: `npm install` — Start command: `npm start`.
4. **مهم جدًا**: لازم تضيف **Persistent Volume/Disk** وتربطه بمسارين: `/data` (أو المسار اللي هيتحط فيه المشروع + `/data`) و `/public/uploads` — لو من غير تخزين دائم، بياناتك وصورك هتتمسح مع كل نشر جديد (Deploy).
5. ضيف Environment Variables: `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `JWT_SECRET` (وحط قيم قوية). لو عايز صوت جوجل الطبيعي بدل صوت المتصفح (شرح كامل فوق في قسم "الصوت والتفاعل الصوتي")، ضيف كمان `GOOGLE_TTS_API_KEY` بمفتاح الـ API بتاع خدمة Google Cloud Text-to-Speech.
6. بعد النشر هيديك رابط عام (Domain) - استخدمه بدل `localhost:3000` في كل حاجة.

### سيرفر خاص (VPS) عادي

```bash
git clone <رابط-المشروع>
cd spinner-app
npm install
npm install -g pm2   # عشان السيرفر يفضل شغال دايمًا ويرستارت لوحده
pm2 start server/index.js --name spinner
pm2 save
```

وحط سيرفر Nginx كـ Reverse Proxy قدامه مع شهادة SSL (مجانية عن طريق Let's Encrypt / certbot) عشان يبقى فيه HTTPS - مهم جدًا لأي تطبيق بيجمع بيانات عملاء.

## 4) نسخ احتياطي للبيانات

كل بياناتك (الكامبينات، العملاء، الصور) متخزنة في مجلدين بس:

- `data/spinner.db` - قاعدة البيانات (الكامبينات + العملاء).
- `public/uploads/` - كل الصور والفيديوهات المرفوعة.

اعمل نسخة احتياطية من المجلدين دول بشكل دوري (خصوصًا قبل أي تحديث للتطبيق).

---

## 5) هيكل المشروع

```
server/
  index.js          نقطة تشغيل السيرفر
  db.js             الاتصال بقاعدة البيانات وإنشاء الجداول
  routes/           auth (تسجيل الدخول) - campaigns (الكامبينات) - leads (العملاء) - upload (رفع الملفات) - public (اللي بتستخدمها صفحة اللعبة)
  utils/            محرك تحديد نتيجة اللفة (spin.js) - تصدير الإكسل (excel.js) - الإعدادات الافتراضية (defaultConfig.js)
public/
  admin/            لوحة التحكم (HTML/CSS/JS)
  play/             صفحة اللعبة (HTML/CSS/JS)
  uploads/          الصور والفيديوهات المرفوعة (بتتعمل تلقائيًا)
data/               قاعدة البيانات (بتتعمل تلقائيًا)
```

لا يحتاج أي أدوات بناء (Build tools) - كله JavaScript عادي.

## 6) الدعم الفني

المشروع مبني بالكامل عشان تقدر تتحكم فيه وتعدّله بحرية - كل الكود واضح ومعلّق بالعربي في أغلب الأماكن المهمة. لو عايز تضيف مميزات زي: تسجيل دخول لأكتر من أدمن بصلاحيات مختلفة، أو ربط بخدمة إيميل/واتساب لإرسال الجوائز تلقائيًا، أو تصدير تلقائي دوري - الكود منظم يسهّل الإضافة عليه.
